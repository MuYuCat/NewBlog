# 个人门户系统详细需求文档 (Product Requirements Document)

本方案围绕 **个人展示门户、游戏轨迹、知识智库、资源宝库** 四大核心板块，定义了各端的功能与交互逻辑。

---

## 0. 认证与访问控制 (Auth & Access)

### 0.1 前后台权限分离

- **前台门户 (blogWeb)**:
  - **定位**: 纯展示性质，无需登录。
  - **访问**: 全公开，所有发布内容均可被访客浏览。
- **后台管理 (blogAdmin)**:
  - **定位**: 核心管理端，负责全站内容的生命周期管理。
  - **登录页**: 采用极简毛玻璃样式，使用 `@newblog/validation` 提供的 `LoginSchema` 进行校验。
  - **安全**: 仅支持单管理员账号（ADMIN 角色），关键操作记录埋点。

---

## 1. 前台门户展示 (blogWeb - Elite UI)

### 1.1 视觉系统 (Elite Typography & Layout)

- **字体系统**:
  - **Heading**: Cormorant Garamond (衬线体，高奢感)。
  - **Body**: Montserrat (现代感) + Noto Serif SC (思源宋体，精致中文字形)。
- **布局策略**:
  - **Desktop Only**: 仅针对宽屏优化，追求极致的 PC 视觉排版。
  - **100vh 叙事**: 首页采用板块化分屏（Hero -> Poetry -> Bento），形成呼吸感。
- **玻璃磨砂**: Header 采用 `blur(20px)` 的 Glassmorphism 效果，随亮暗模式自适应。

### 1.2 心语板块 (Whisper - Masonry Layout)

- **定位**: 碎片化情绪、随笔与“喃喃自语”。
- **布局策略**:
  - **瀑布流展示 (Waterfall/Masonry)**: 文章不再以标准列表排序，而是以卡片形式错落排布，追求视觉上的灵动感。
  - **全内容呈现**: 不同于正式博客只展示摘要，心语卡片将文章内容（Content）完整平铺，类似“标签墙”或“即时贴”的效果。
- **视觉风格**:
  - **卡片继承**: 基础样式（圆角、阴影、边框）与主文章列表保持一致，确保全站 Elite UI 的统一性。
  - **自适应高度**: 根据内容长短动态调整卡片高度，形成自然的瀑布流错落。
  - **沉浸感**: 背景延续亮暗模式变量，卡片悬浮触发微小位移与阴影加深效果。

## 2. 后台管理系统 (blogAdmin - Elite Admin)

### 2.1 视觉规范

- **风格**: 延续前台的小众高奢质感，拒绝传统企业级样板。
- **UI 框架**: UmiJS v4 + Ant Design v5 (深度定制 Token，圆角 12px~32px)。
- **交互**: 采用浮动侧边栏、大面积留白与 GSAP 平滑过渡。

### 2.2 核心功能模块

1.  **用户管理 (User & Auth)**
    - 管理员个人信息维护：修改姓名、账号、密码、头像。
    - 会话管理：查看当前登录状态与安全策略。
2.  **菜单管理 (Navigation CMS)**
    - 全站导航项配置：支持二级菜单，绑定 i18n 多语言 Key。
    - 动态路径映射与图标分配。
3.  **游戏管理 (Game Sync)**
    - **统计筛选**: 列出账号下所有关联游戏，勾选的游戏才进入统计与前台展示。
    - **原始数据**: 监控从 Steam/PSN 等三方 API 抓取的数据流，支持手动触发重构。
4.  **文章管理 (Content CMS)**
    - 涵盖：知识智库、个人博客、日常随笔。
    - 功能：分类目录树、列表展示、权限管理、全功能编辑器。
5.  **资源宝库 (Vault Management)**
    - 资源剪藏：链接分类（工具、灵感等）、编辑备注、私密状态控制。
6.  **日志管理 (Analytics)**
    - **全站行为埋点**: 采用影子请求技术（`/api/visit`），实现 Web 与 Admin 端的页面级 PV/UV 监控。
    - **操作审计日志**: 利用 NestJS 拦截器自动记录所有管理端写操作（POST/PATCH/DELETE）的 Payload 与响应状态。
    - **地理溯源**: 自动通过访问者 IP 解析国家、省份、城市级别的位置信息。
    - **数据分析**: 可视化仪表盘，展示流量趋势、热门内容排行及跨端行为分布。
7.  **智能文档解析 (MinerU Sync) - 必做**
    - **算力节点集成**: 利用物理 Mac Mini (M系列) 部署 `MinerU-webui` 算力节点，通过 API 暴露解析服务。
    - **精英发射中心 (Elite Launch Center)**:
      - **Bento 布局**: 在编辑器上方集成 `blur(20px)` 磨砂玻璃感的上传区。
      - **物理启动反馈**: 解析时图标由静止转为“轨道模型”旋转动画（GSAP），Markdown 结果以“流式打字机”效果填入。
    - **远程指挥塔 (The Command Tower)**:
      - **物理状态观测**: 使用 Matter.js 模拟状态球（离线-单色，就绪-霓虹绿）。
      - **按需唤醒 (On-Demand Wake)**:
        - 后台支持“一键启动/关闭”模型服务。
        - **启动预热 (Warm-up)**: 启动阶段展示 0-100% 物理进度条（预估 20-30s）。
        - **自动休眠 (Auto-Idle)**: 模型服务检测到 30 分钟无活动后，自动执行停机，释放 16GB+ 内存。
    - **知识解构 (Knowledge Deconstruction)**: 前端支持 PDF 碎裂并转化为“坠落成海”物理特效的实验性展示。
    - **极速转换**: 实现 PDF 到 Markdown 的精排转换，支持复杂公式、表格、布局的完美保留。
    - **安全性**:
      - **鉴权**: 所有请求经过 `SECRET_TOKEN` 鉴权与公网安全隧道（内网穿透）转发。
      - **反滥用 (Anti-Abuse)**:
        - **频率限制 (Rate Limiting)**: 单个 IP 每小时限制调用 X 次，防止恶意刷量。
        - **集中式攻击防护**: 检测到单 IP 在短时间内（如 1 分钟内）进行集中式高频调用时，自动触发封禁机制。
        - **黑名单系统 (IP Banning)**: 被封禁的 IP 在 24 小时内禁止访问所有解析接口，后台管理端可手动解除封禁。
8.  **智能 PPT 镜像重构 (EPR Sync) - 必做**
    - **全要素重构**: 严禁采用“截图背景 + 透明字”的低端方案，必须实现真正的原生组件重写。
    - **三层蛋糕架构 (Triple-Layer)**:
      - **底层 (Visual Anchor)**: 通过 AI Inpainting 修复背景图，实现视觉 1:1 镜像。
      - **中层 (Structure)**: 利用 MinerU 提取原生表格、坐标与 LaTeX 公式，映射为 PPT 矢量对象。
      - **顶层 (Semantic)**: 调用多模态 API 进行布局微调，自动匹配最接近的系统字体与排版参数。
    - **物理交互叙事**: 生成过程中，前端应展示从“图片解构”到“零件吸附组装”的 Matter.js 动效，模拟物理级的重构感。

## 3. 技术实现要点 (Key Tech Specs)

- **框架**: Astro (Web) / NestJS (Api) / UmiJS (Admin)。
- **动效**: GSAP + ScrollTrigger。
- **样式**: CSS Variables + SCSS + Tailwind (Admin)。
- **校验**: 全程引用 `@newblog/validation`。
