## 2. 关键技术方案

### 2.1 主实体聚合架构 (Master-Entity Mapping)

- **主实体 (Master)**: 以游戏为中心（如：艾尔登法环），作为前台展示的唯一入口。
- **关联层 (Platform)**: 每个主实体可挂载多个平台记录（PS5, Steam, Switch），聚合各平台的游玩时长与奖杯。
- **匹配引擎**: 预留 IGDB 接口位置，未来将通过全球唯一 ID 实现 100% 自动匹配。

### 2.2 工业级安全锁 (Safety Valve 2.0)

- **环境隔离**: 强制本地调试 (DEV) 与 线上同步 (PROD) 使用同一数据库锁，彻底杜绝本地调试导致账号资产受损的风险。
- **熔断机制**: 引入 `RISK` 状态，一旦接口返回认证风险信号，系统物理熔断一切自动同步，强制管理员手动介入。
- **智慧冷却**: 成功进入 120min CD，失败仅 5min CD。

### 2.3 平台风险矩阵分析

- **结论**: PSN 属于高危无官方接口平台，严禁任何高频轮询行为。
- **策略**: 获取一次 Token 后缓存 1 小时，每天同步频率建议控制在 2-4 次。
