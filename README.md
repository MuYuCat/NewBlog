# NewBlog: 企业级全栈个人门户系统

本项目是一个集 **游戏轨迹、知识智库、资源宝库** 于一体的全栈个人门户系统，采用现代化的 **Monorepo** 架构进行开发与管理。

## 🛠️ 技术栈快照

| 模块 | 技术框架 | 核心依赖 |

## 🚀 快速开始 (规划中)

本项目采用 **pnpm Monorepo** 架构。

1. **环境准备**: 安装 `nvm` 和 `pnpm`。
2. **初始化**: `pnpm install`。
3. **启动**: `pnpm dev`。
