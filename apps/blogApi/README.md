# 🧠 blogApi - 整个博客系统的“智慧大脑”

欢迎来到 **NewBlog** 的后端核心！如果把整个博客系统比作一家餐厅，那么 `blogWeb` 和 `blogAdmin` 就是精美的**菜单和餐桌**，而 `blogApi` 就是那间忙碌的**厨房**。

这里不负责“长得漂亮”，只负责“逻辑正确”和“数据安全”。

---

## 🌟 小白科普：这里都有什么？

### 1. NestJS —— “全能主厨” (逻辑指挥中心)

它是后端的主框架。它像一位经验丰富的主厨，决定了每一个请求（比如“我要看文章”或“我要登录”）该由谁来处理，如何处理，并确保厨房里的秩序井然。

### 2. Prisma —— “数据库翻译官” (ORM)

我们要把数据存进 MySQL 数据库，但程序员不喜欢写复杂的 SQL 语句。**Prisma** 就像一个贴心的翻译官：

- 你告诉它：`user.create({ name: '张三' })`
- 它自动翻译成数据库听得懂的语言并存进去。
- 我们使用的是 **Prisma 6** 版本，它像老牌翻译官一样稳健。

### 3. MySQL —— “巨型资料库” (数据库)

这是我们存放所有文章、用户信息、游戏记录的**保险柜**。只要不删库，数据就永远在这里。

### 4. JWT —— “电子通行证” (身份认证)

当你登录成功后，大厨会给你发一张带有加密签名的“电子通行证”。下次你来找大厨要私密数据时，只要出示这张票，大厨就知道是你本人了。

## 🛠️ 快速上手：如何让大脑转起来？

即使你是第一次接触后端，按照下面三步也能跑起来：

### 第一步：准备“翻译机”依赖

在项目根目录下运行，把大厨需要的工具都买回来：

```bash
pnpm install
```

### 第二步：同步“保险柜”结构 (Prisma)

大厨需要根据图纸在 MySQL 里摆放货架（建表）。请进入 `apps/blogApi` 目录运行：

```bash
# 1. 把图纸同步到数据库 (会自动创建 newblog 数据库和表)
npx prisma migrate dev --name init

# 2. 让翻译官更新一下词典 (生成代码提示)
npx prisma generate
```

### 第三步：点火开工！

回到根目录，运行启动命令：

```bash
pnpm run dev:api
```

如果你看到 `Nest application successfully started`，说明大脑已经上线！

## 📂 厨房重地：文件夹里装了什么？

- `src/`：**核心代码区**。
  - `main.ts`：厨房的电源总开关。
  - `app.module.ts`：厨房的平面图，记录了有哪些部门。
  - `prisma.service.ts`：连接保险柜的专用通道。
- `prisma/`：**数据库图纸区**。
  - `schema.prisma`：定义了用户长什么样、文章长什么样。
  - `migrations/`：记录了保险柜结构的每一次改动历史。
- `.env`：**秘密笔记本**。存放数据库密码和加密钥匙，千万不要泄露给别人！

---

## 🤝 全栈协作：它如何与别人聊天？

- **Admin (后台)**：通过 `blogApi` 修改文章、同步游戏数据。
- **Web (前台)**：通过 `blogApi` 读取文章内容展示给读者。
- **Validation (校验包)**：它是厨房门口的**安检员**。不管是前台还是后台发来的数据，都要先经过安检员（Zod）检查，缺胳膊少腿的数据一律踢出去！
